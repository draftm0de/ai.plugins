You add this marketplace once and install the Plugin Manager from it. A marketplace is a catalogue that lists plugins. A plugin is an installable package with guidance for the assistant, called skills.

## What it offers

The marketplace `draftmode-ai-plugins` is meant for Claude and Codex. It lists one plugin:

| Plugin | What it is for |
| --- | --- |
| [Plugin Manager](https://github.com/draftm0de/ai.plugin.plugin-manager) | Create, associate, document and check marketplaces and plugins. |

The plugin lives in its own repository. The marketplace holds only the catalogues. Address to add: `https://github.com/draftm0de/ai.plugins`.

## Who it is for

For everyone who wants to use the Plugin Manager in Claude or Codex. You need your own access and permissions for the repository.

If you maintain the marketplace, read [Development](docs/en/development.md).
