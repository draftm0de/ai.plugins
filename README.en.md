You add this marketplace once and install the plugins you need from it. A marketplace is a catalogue that lists plugins. A plugin is an installable package with guidance for the assistant, called skills.

## What it offers

The marketplace `draftmode-ai-plugins` is meant for Claude and Codex. It lists four plugins:

| Plugin | What it is for |
| --- | --- |
| [Plugin Manager](https://github.com/draftm0de/ai.plugin.plugin-manager) | Create, associate, document and check marketplaces and plugins, and publish them after your approval. |
| [Interview Coach](https://github.com/draftm0de/ai.plugin.interview-coach) | Practise job interviews for your role, with feedback, interviewer research and private training progress. |
| [Website Manager](https://github.com/draftm0de/ai.plugin.website) | Create and maintain websites: setup, start page design, local preview, search engine and accessibility audits. It cannot publish yet. |
| [Coding Manager](https://github.com/draftm0de/ai.plugin.coding) | Set up, check and update coding plugins for development projects. |

Each plugin lives in its own repository. The marketplace holds only the catalogues. Address to add: `https://github.com/draftm0de/ai.plugins`.

## Who it is for

For everyone who wants to use these plugins in Claude or Codex. You need your own access and permissions for the repositories.

If you maintain the marketplace, read [Development](docs/development.md).
