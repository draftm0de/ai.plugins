# Documentation style

How the documentation of this repository is written. This file belongs to the repository; the Plugin Manager never changes it.

- Address the reader as "you" (German: "du").
- Start with what the reader gains, then how it works.
- Short sentences and concrete verbs. No marketing words, no superlatives.
- Explain a technical term the first time.

Example: "Add the marketplace once. After that you install the plugin with one click."
