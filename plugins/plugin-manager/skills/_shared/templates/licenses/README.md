# License text provenance

MIT.txt contains the standard MIT grant and disclaimer, checked against the Open
Source Initiative text at https://opensource.org/license/mit on 2026-11-19.
Only the copyright year and rights-holder placeholders are filled from confirmed
user inputs. The existing repository MIT text supplied the plain-text formatting.
Its publisher and copyright notice are not inherited by generated plugins.

Other license texts must be explicitly supplied and confirmed; this tool does not
infer their identifier, assess their legal applicability or generate new terms.
