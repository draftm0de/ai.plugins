## Marketplace

A marketplace is a catalogue that lists plugins. You add it once in your app or CLI; after that you can install and update plugins from it.

## Plugin

A plugin is an installable package with one or more skills and the files they need.

## Skill

A skill is the guidance for one task. You call it, or the assistant picks it by its description. With several skills the call names it: `/<plugin>:<skill>`.
