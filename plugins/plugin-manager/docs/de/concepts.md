## Marketplace

Ein Marketplace ist ein Katalog, der Plugins auflistet. Du fügst ihn einmal in deiner App oder CLI hinzu; danach kannst du daraus Plugins installieren und aktualisieren.

## Plugin

Ein Plugin ist ein installierbares Paket mit einem oder mehreren Skills und den Dateien, die sie brauchen.

## Skill

Ein Skill ist eine Anleitung für eine Aufgabe. Du rufst ihn auf, oder der Assistent wählt ihn anhand seiner Beschreibung. Bei mehreren Skills trägt der Aufruf den Namen: `/<plugin>:<skill>`.
